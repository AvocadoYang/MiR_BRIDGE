一、通訊架構

WISE-4060（4 路數位輸入 DI ＋ 4 路繼電器輸出 DO 的乙太網路 I/O 模組）做為控制系統與電梯控制盤之間的訊號橋樑。控制系統不直接接線到電梯，而是透過 DO（繼電器輸出）送出指令，再以 DI（數位輸入）讀取電梯回傳的狀態接點，完成雙向交握。

訊號方向定義： · DO= 控制系統 → 電梯（命令輸出，繼電器接點）
· DI= 電梯 → 控制系統（狀態回授，讀取電梯接點）
· 所有訊號皆為保持型（準位）訊號：接點導通期間代表 1、斷開代表 0，並非脈衝。
· 本文件位元值一律由左至右寫為 ch3 ch2 ch1 ch0，最右邊為最低位元 ch0。

樓層編碼備註：DO 與 DI 使用相同的樓層編碼。控制系統以「DI 所在樓層 = DO 目標樓層」判斷電梯已抵達，不另設到達訊號，因此電梯端需在停妥於該樓層時才輸出對應的樓層編碼，行進中請輸出 00。

四、交握流程範例（專屬控制 → 前往 5 樓 → 開門 → 釋放）

送出 DO 指令後，控制系統會輪詢對應的 DI，等到狀態符合或逾時才進行下一步，而不是送出 DO 就直接視為動作完成。

  1. DO = 0001：DO0 = 1，申請專屬模式
  2. 輪詢 DI0：等待 DI0 = 1（專屬模式啟動中）才進行下一步
  3. DO = 1001：保持 DO0 = 1，DO3/DO2 = 10，指定前往 5 樓
  4. 輪詢 DI3/DI2：等待 DI3/DI2 = 10（已在 5 樓）
  5. DO = 0001：抵達後控制系統將 DO3/DO2 歸零（00），專屬模式維持
  6. DO = 0011：DO1 = 1，按住開門；輪詢 DI1 = 1（門已完全開啟）
  7. DO = 0001：AMR 進出完成後 DO1 = 0，放開開門鍵
  8. DO = 0000：DO0 = 0，取消專屬模式；DI0 回到 0，結束本次交握
協議設計提醒：每一組「命令 → 回授」控制系統皆有逾時保護。發生異常或取消時，控制系統會將 DO 全部歸零（0000）。
